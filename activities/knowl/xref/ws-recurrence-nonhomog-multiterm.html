Problem 1.

Find a particular solution \(f_{1}\) of \((A-4)f(n) = 2\cdot 3^{n} + 5n3^{n} -15 n+2\text{.}\)
🔗
Solution.
Try \(f_{1}(n) = d_{1} 3^{n} + d_{2} n3^{n} + d_{3}n + d_{4}\text{.}\) We then find
\begin{equation*} (A-4)f_{1}(n) = (3d_{2}-d_{1}) 3^{n}+ -d_{2} n 3^{n} -3d_{3} n + d_{3}-3d_{4}. \end{equation*}
From this we see that we need \(-d_{2}=5\text{,}\) or \(d_{2} = -5\text{.}\) We also need \(3d_{2}-d_{1} = 2\text{,}\) so \(d_{1}=-17\text{.}\) Continuing to match coefficients, we find \(-3d_{3} = -15\) or \(d_{3}=5\text{.}\) We also have \(d_{3} - 3d_{4} = 2\text{,}\) so \(5-3d_{4} = 2\) and \(d_{4} = 1\text{.}\) Thus,
\begin{equation*} f_{1}(n) = -17\cdot 3^{n} -5n3^{n} +5n +1\text{.} \end{equation*}
