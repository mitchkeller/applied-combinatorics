    Bob’s Claims:
    1. Only linear orders have paths as cover graphs.
      🔗
      This is false. Consider a poset of height \(2\) whose diagram is a zig-zag shape. The cover graph is still a path, but the poset is not a lienar order.
      🔗
      🔗
    2. A poset and its dual have the same cover graph and the same comparability graph.
      🔗
      This is true. Cover relations and comparabilities are reversed, but since the cover graph and comparability graph are not directed, this doesn’t change the graphs.
      🔗
      🔗
    3. Any two posets with the same cover graph have the same height and the same width.
      🔗
      This is false. Consider the zig-zag poset mentioned earlier and compare it to a linear order on the same number of points.
      🔗
      🔗
    4. Any two posets with the same comparability graph have the same height and the same width.
      🔗
      This is true because heighth of a poset is the clique number of the comparability graph and width of a poset is the size of a largest independent set in the comparability graph.
      🔗
      🔗

    Height and Antichain Partitioning.

    Theorem 6.10. Dual of Dilworth’s Theorem.

    A poset \(\bfP=(X,P')\) has height \(h\) if and only if \(h\) is the smallest number so that there exist \(h\) disjoint antichains \(A_{1},\dots, A_{h}\) with
    \begin{equation*} X= A_{1}\cup A_{2}\cup\cdots\cup A_{h}\text{.} \end{equation*}
    🔗
    🔗

    Proof by algorithm.

    • Let \(\bfP_{1} = \bfP\text{.}\) Place minimal elements of \(\bfP_{1}\) in \(A_{1}\text{.}\) Let \(\bfP_{2}\) be formed from \(\bfP_{1}\) by deleting the points in \(A_{1}\text{.}\) Place minimal elements of \(\bfP_{2}\) in \(A_{2}\text{.}\)
      🔗
      🔗
    • General step: Form \(\bfP_{i+1}\) by removing \(A_{i}\) from \(\bfP_{i}\text{.}\) Let \(A_{i+1}\) be the minimal elements of \(\bfP_{i+1}\text{.}\)
      🔗
      🔗
    • Continue until every point is in an antichain.
      🔗
      🔗
    🔗
    🔗
    
    The order diagram of a poset with 7 points. The points are labeled with letters from \(a\) to \(f\text{.}\)
    🔗
    The partition the algorithm produces here is
    \begin{align*} A_1 \amp = \set{b,f}\\ A_2 \amp = \set{a,c}\\ A_3 \amp = \set{d,g}\\ A_4 \amp = \set{e} \end{align*}
    Thus, the height is \(4\text{,}\) which is demonstrated by the chain \(\set{e,d,c,b}\text{.}\) We obtain this chain by starting with an element of \(A_4\) and working down the poset, always moving to a point with label one smaller.
    🔗

    Chain Partitioning and Width.

    Let’s look back at the Dual of Dilworth’s Theorem. What would be a similar result for width?
    🔗

    Theorem 6.11. Dilworth’s Theorem.

    Let \(\bfP=(X,P')\) be a poset. Then \(w\) is the width of \(\bfP\) if and only if \(w\) is the smallest number so that there exist \(w\) disjoint chains \(C_{1},C_{2},\dots C_{w}\) with
    \begin{equation*} X=C_{1}\cup C_{2}\cup \cdots\cup C_{w}. \end{equation*}
