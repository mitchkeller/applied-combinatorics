    Handout 3.2 Principle of Mathematical Induction
    

    Axiom 3.2. Principle of Mathematical Induction.

    Let \(S_{n}\) be an open statement involving a positive integer \(n\text{.}\) If \(S_{1}\) is true, and for every positive integer \(k\text{,}\) the statement \(S_{k+1}\) is true whenever \(S_{k}\) is true, then \(S_{n}\) is true for every positive integer \(n\text{.}\)
    🔗
    We can rephrase “the statement \(S_{k+1}\) is true whenever \(S_{k}\) is true” as “if \(S_k\) is true, then \(S_{k+1}\) is true”.
    🔗
    🔗

    Key Parts of an Inductive Proof.

    When trying to prove an open statement \(S_{n}\) is true for all positive integers \(n\) by mathematical induction, the key steps are
    Basis Step
    🔗
    Show that \(S_{1}\) is true.
    🔗
    We sometimes call this the “Base case”.
    🔗
    Inductive step
    🔗
    Show that if for some \(k\geq 1\text{,}\) \(S_{k}\) is true, then \(S_{k+1}\) is true.
    🔗
    “For some \(k\geq 1\text{,}\) \(S_{k}\) is true” is usually referred to as the induction hypothesis or inductive hypothesis.
    🔗
    🔗
    🔗
    PI questions: getting started, after basis step, after IH.
    🔗

    Theorem 3.3.

    For all positive integers \(n\text{,}\) \(\displaystyle \sum_{i=1}^{n} (4i-3) = n(2n-1)\text{.}\)
    🔗
    🔗

    Proof.

    We will prove this by induction. The basis step is to substitute \(n=1\) into each side:
    \begin{align*} \sum_{i=1}^1 (4i-3) \amp = 4\cdot 1-3 = 1\\ 1(2\cdot 1-1) \amp = 1(2-1) = 1\cdot 1 = 1 \end{align*}
    These are equal, so the basis step is complete. Now assume that for some \(k\geq 1\) we have
    \begin{equation*} \sum_{i=1}^k (4i-3) = k(2k-1)\text{.} \end{equation*}
    We want to prove that
    \begin{equation*} \sum_{i=1}^{k+1} (4i-3) = (k+1)(2(k+1)-1)\text{.} \end{equation*}
    We can write
    \begin{align*} \sum_{i=1}^{k+1} (4i-3) \amp = \sum_{i=1}^k(4i-3)+(4(k+1)-3)\\ \amp = k(2k-1)+(4(k+1)-3)\qquad\text{(By the induction hypothesis)}\\ \amp = 2k^2-k+4k+1 = 2k^2+3k+1\\ \amp = (k+1)(2k+1)\\ \amp = (k+1)(2(k+1)-1)\text{.} \end{align*}
    Thus, the formula is true for \(k+1\) and therefore holds for all \(n\geq 1\) by the Principle of Mathematical Induction.
    🔗
    🔗

    Activity 3.4.

    (a)

    Recall that we have defined \(r(n)\) to be the number of regions in the plane determined by \(n\) lines arranged so that (1) each pair of lines intersects and (2) no three lines intersect at a single point and argued that \(r(1) = 2\) and for \(n\geq 2\text{,}\) \(r(n) = r(n-1) + n\text{.}\) Prove that for all positive integers \(n\text{,}\)
    \begin{equation*} r(n) = \binom{n+1}{2}+1\text{.} \end{equation*}
    🔗
    Solution.

    Proof.

    We will prove this by induction. For the base case, let \(n=1\text{.}\) By definition, \(r(1) = 1\text{.}\) We also see that \(\binom{1+1}{2} + 1 = \binom{2}{2} +1 = 1+1 = 2\text{,}\) which completes the verification of the base case.
    🔗
    Now assume that for some \(k\geq 1\) that \(r(k) = \binom{k+1}{2} + 1\text{.}\) We will show that \(r(k+1) = \binom{k+2}{2}+1\text{.}\) Since \(k\geq 1\text{,}\) we have that \(k+1\geq 2\text{.}\) Therefore, the recursive formula for \(r\) applies to \(r(k+1)\text{,}\) and we have
    \begin{align*} r(k+1) \amp = r(k) + (k+1)\\ \amp = \binom{k+1}{2} + 1 + k+1 \amp \text{(By induction hypothesis)}\\ \amp = \frac{(k+1)k}{2} + k+2 = \frac{k^2+k}{2} + \frac{2k+4}{2}\\ \amp = \frac{k^2+3k+4}{2} = \frac{(k+2)(k+1) + 2}{2}\\ \amp = \binom{k+2}{2} + 1\text{.} \end{align*}
    Therefore, by the Principle of Mathematical Induction,
    \begin{equation*} r(n) = \binom{n+1}{2}+1 \end{equation*}
    for all positive integers \(n\text{.}\)
    🔗
    🔗
    🔗
    🔗

    (b)

    We say that an integer \(a\) divides an integer \(b\) provided that there exists an integer \(m\) such that \(b=ma\text{.}\) Prove that for all integers \(n\geq 1\text{,}\) \(4\) divides \(5^{n}-1\text{.}\)
    🔗
    Solution.

    Proof.

    We will prove this by induction. The basis step is \(n=1\text{,}\) for which we have \(5^1-1=4=1\cdot 4\text{.}\) Therefore, we can see that \(4\) divides \(5^1-1\) as required.
    🔗
    Now assume that for some positive integer \(k\text{,}\) we have that \(4\) divides \(5^k-1\text{.}\) This means that there exists an integer \(m\) so that \(5^k-1=4m\text{.}\) We can rearrange this to say that \(5^k=4m+1\text{.}\) Now we consider \(5^{k+1}-1\) for the induction step. We can write \(5^{k+1}\) as \(5^k\cdot 5\text{,}\) so we have \(5^{k+1}-1 = 5^k\cdot 5 -1 = (4m+1)\cdot 5 -1\) by the induction hypothesis. Using algebra, we now have that this equals \(20m+5-1 = 20m+4=4(5m+1)\text{.}\) Since \(m\) is an integer, \(5m+1\) is also an integer. Therefore, \(5^{k+1}-1\) is four times an integer, which is what it means for \(4\) to divide \(5^{k+1}-1\text{.}\) Hence, by the Principle of Mathematical Induction, \(4\) divides \(5^n-1\) for all positive integers \(n\text{.}\)
    🔗
    🔗
    🔗
    🔗

    (c)

    Let \(f(1)=5\text{,}\) \(f(2) = 13\text{,}\) and for all integers \(n\geq 3\text{,}\)
    \begin{equation*} f(n)=5f(n-1)-6f(n-2). \end{equation*}
    Prove that an explict formula for \(f(n)\) is given by \(f(n)=2^{n}+3^{n}\text{.}\)
    🔗
    Solution.

    Proof.

    We will prove this using strong induction. Because the recursive formula only applies for \(n\geq 3\text{,}\) we will need to address \(n=1\) and \(n=2\) as base cases. We are given that \(f(1) = 5\) and \(f(2) = 13\text{.}\) The formula \(2^n+3^n\text{,}\) when considered for \(n=1\) and \(n=2\text{,}\) yields \(2^1+3^1 = 5\) and \(2^2+3^2 = 4+9 = 13\text{,}\) respectively. Thus, the basis step is complete.
    🔗
    Now assume that for some integer \(k\geq 2\) and all integers \(j\) with \(1\leq j\leq k\) that \(f(k) = 2^k+3^k\text{.}\) We must prove that \(f(k+1) = 2^{k+1}+3^{k+1}\text{.}\) Since \(k\geq 2\text{,}\) we have that \(k+1\geq 3\text{,}\) and thus the recursive formula for \(f\) applies. Therefore,
    \begin{align*} f(k+1) \amp = 5f(k)-6f(k-1)\\ \amp = 5(2^k+3^k) -6(2^{k-1}+3^{k-1})\amp \text{(By the inductive hypothesis)}\\ \amp = 5\cdot 2^k + 5\cdot 3^k - 6\cdot 2^{k-1} -6\cdot 3^{k-1}\\ \amp = 5\cdot 2^k + 5\cdot 3^k -3\cdot 2^k -2\cdot 2^k\\ \amp = 2\cdot 2^k +3\cdot 3^k\\ \amp = 2^{k+1} + 3^{k+1}\text{.} \end{align*}
    This is what we needed to show. Therefore, by the Principle of Mathematical Induction, we have that for all integers \(n\geq 1\text{,}\) \(f(n) = 2^n + 3^n\text{.}\)
