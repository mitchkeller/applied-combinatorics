Problem 1.

If we try using \(f_{1}(n) = dn\) as a particular solution of \((A+1)(A-4)f(n) = 12n\text{,}\) we find the following:
\begin{align*} (A+1)(A-4)[dn]\amp = (A+1)[d(n+1)-4dn] = (A+1)[-3dn + d]\\ \amp= -3d(n+1)+d-3dn+d = -6dn - 6d\text{.} \end{align*}
Why is this an issue?
🔗
Solution.
If we want this to be \(3n\text{,}\) then we simultaneously need \(d=-2\) and \(d=0\text{.}\) Last time I checked, that’s not going to work.
