Task 9.1.1.c.

Since we already know that \(f_{1}(n) = c_{1} 3^{n}\) is a solution of \((A-3)f=0\) (and thus \((A-3)^{2}f=0\)), adding it to \(f_{2}\) gives a two parameter family of solutions. Find \(c_{1}\) and \(c_{2}\) so that \(f(n) = c_{1}3^{n}+c_{2}n3^{n}\) is a solution of \((A-3)^{2}f=0\) if \(f(0)=1\) and \(f(1) = 4\text{.}\)
🔗
Solution.
We find that \(f(0)=c_{1}\) and \(f(1) = 3c_{1} + 3c_{2}\text{.}\) We know the former is \(1\text{,}\) so \(c_{1}=1\text{.}\) Since \(f(1)=4\) and \(c_{1} = 1\text{,}\) we see that \(4=3+3c_{2}\text{.}\) Hence \(c_{2} = 1/3\text{.}\)
